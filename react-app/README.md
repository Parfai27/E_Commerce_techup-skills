# Selz

React storefront for the KLab TechUp Skills API. It sits next to `node-app` in the same repository. Setup and the list of API screens are in the API [README](../node-app/README.MD).

```bash
npm install
npm run dev
```

The dev server runs at http://localhost:5173 and proxies `/api` to the API on http://localhost:1000. Start that API with `npm run dev` inside `node-app`.
